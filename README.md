### SmartStudy AI — Cross-Platform Mobile Study Application

SmartStudy AI is an AI-powered productivity and utility mobile application designed to optimize student workflows. Built as a Final-Year Capstone Project, the platform combines a robust full-stack architecture with native system services and artificial intelligence. 

### 🚀 Key Features

* **AI-Driven Content Generation:** Integrated the OpenRouter API (Gemini 2.5 Flash Lite) to auto-generate personalized flashcards, concise summaries, and mock quizzes from study material.
* **Native Focus Mode:** Engineered a custom Android utility using Kotlin AccessibilityService and ForegroundService to lock distracting applications, display an active floating timer, and capture real-time application usage metrics.
* **Secure Backend Architecture:** Deployed a Laravel 11 framework with a MySQL database layout, utilizing secure Laravel Sanctum token management, multi-device session persistence, and custom email OTP verification flows.
* **Modern State Management:** Architected the front-end tracking layer cleanly using Flutter and Riverpod for dynamic multi-theme navigation and data caching.

### 🛠️ Technical Stack

* **Frontend:** Flutter, Dart, Riverpod, Dio, Flutter Secure Storage
* **Backend & Databases:** Laravel 11, PHP, MySQL, Laravel Sanctum
* **Native Services:** Kotlin, Android Accessibility API, UsageStatsManager
